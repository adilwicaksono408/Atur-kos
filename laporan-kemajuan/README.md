# Sistem Pelacakan Kemajuan (Progress Tracker)
## Kos Princess: Project & Skripsi

Folder ini dibuat khusus untuk mencatat dan mengelola **kemajuan konkret (deliverables)** harian dari pengembangan aplikasi **Kos Princess** dan penulisan **Naskah Skripsi**, sesuai arahan dosen pembimbing.

---

## 📁 Struktur Folder

```text
d:/Kos Princess/laporan-kemajuan/
│
├── README.md                     # Panduan penggunaan & aturan pelaporan harian
├── TEMPLATE-LAPORAN-DOSEN.md     # Template pesan WA/email siap copy-paste ke dosen
├── LOGBOOK-HARIAN.md             # Log harian (timeline capaian konkret per hari)
├── PROGRESS-PROJECT.md           # Matriks status fitur & modul aplikasi Kos Princess (dari PRD)
├── PROGRESS-SKRIPSI.md           # Matriks status bab, subbab, diagram, dan dokumen skripsi
│
└── bukti-progres/                # Folder penyimpanan screenshot, diagram, & lampiran file
```

---

## ⚡ Aturan Emas Pelaporan Harian ke Dosen

1. **Bukan Belajar, Bukan Rencana:**  
   Hindari menulis *"Hari ini belajar Next.js"* atau *"Rencana besok mau buat database"*.  
   Gunakan: *"Selesai membuat skema tabel `rooms` dan `tenants` di Supabase lengkap dengan RLS policy."*
2. **Berbasis Artefak (Bukti Konkret):**  
   Setiap poin capaian harus memiliki bukti fisik/digital (file kode, screenshot UI, diagram, atau naskah bab yang bertambah halamannya).
3. **Dua Pilar Setiap Hari:**  
   Selalu laporkan 2 komponen:
   * **Pilar 1:** Kemajuan Project (Aplikasi / Database / Fitur).
   * **Pilar 2:** Kemajuan Dokumen Skripsi (Bab / Subbab / Diagram / Referensi).
4. **Komitmen Output Besok:**  
   Tuliskan 1 hal konkret yang dijanjikan selesai besok agar dosen tahu arah kerja Anda.

---

## 🚀 Alur Kerja Harian

1. Buka `PROGRESS-PROJECT.md` dan `PROGRESS-SKRIPSI.md` untuk memilih apa yang dikerjakan hari ini.
2. Kerjakan bersama AI / mandiri.
3. Catat hasil kerja di `LOGBOOK-HARIAN.md`. Simpan tangkapan layar di folder `bukti-progres/`.
4. Salin template dari `TEMPLATE-LAPORAN-DOSEN.md`, isi poin capaian hari ini, lalu kirimkan ke dosen via WhatsApp.
